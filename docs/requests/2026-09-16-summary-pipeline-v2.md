# notebooklm-st 기능 추가

## 1. 개요

notebooklm-st을 사용하면서 불편했던 사항들과 몇 가지 자동화 기능을 추가한다.

## 2. 무엇이 불편했나?

1. 유투브 영상을 요약한 문서에서 메타데이터를 사용자가 직접 입력해야 한다.
    - 요약본의 "개요"에 채널명이 "모름"으로 작성된다.
    - NotebookLM의 응답에서는 채널명을 확인하지 못하고 "모름"으로 채우기 때문이다.

2. "이력" 기능에는 문서 검색이나 확인 및 가공을 위한 어떠한 기능도 없다.
    - 요약본를 수정/삭제 하거나 markdown 파일로 다운로드 하는 기능만 수행한다.
    - 해당 문서를 가공할 수 있는 수단으로 사용할 수 없다.

3. 유투브 영상을 요약하는 기능만 수행할 뿐, 가지고 있는 요약본들을 활용하여 가공하는 기능은 없다.
    - 말 그대로 유투브 영상을 요약하는 것에만 충실하다.

## 3. 요구 기능

1. 요약본 최상단에 메타데이터를 작성한다.
    - 메타데이터는 YAML frontmatter 형식을 사용한다.
    - 메타데이터에 작성할 항목: 영상명, 채널명, 업로드일자, 영상URL
1. 유투브 영상 URL을 통해 채널명, 영상명, 업로드 일자를 추출하여 요약본의 메타데이터를 작성한다.
3. 요약본를 로컬 sqlite가 아닌 outline (개인 위키)에 저장한다.
    - 기존에는 로컬에서만 사용할 수 있어서 요약본를 외부에서 볼 방법이 없었다.
    - outline에는 데이터 백업이 적용되어 있으므로 별도의 관리가 필요없다.
    - notebooklm-st 에는 outline에 저장한 문서의 URL과 문서명만 가지며, 사용자에겐 대시보드를 통해 문서명과 URL 링크만 제공한다 (문서 수정/삭제 기능은 outline에 위임)
4. 사용자가 선택한 요약본들을 outline 으로 부터 읽어와서 정리본을 작성한다.
    - notebooklm-st 대시보드에서 특정 요약본을 선택하고 해당 요약본들만 가공하여 정리본을 작성한다.
    - 작성한 정리본의 제목을 사용자로부터 확인받고 저장 버튼을 클릭하면 outline에 저장한다.
5. 즐겨찾기에 추가되어 있는 채널들에 대해 주기적으로 신규 영상을 확인한 다음 요약본을 자동 생성한다.
